# Дорожная карта аудита: клиника доктора Мушулова

Страница прогресса аудита отдела продаж от Smile Sales Agency.
Vite + React + Tailwind + Framer Motion. Без бэкенда и логина, страница закрыта от поисковиков (noindex).

Сайт: https://bmkagencykz-boop.github.io/roadmap-mushulov/

## Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173).

Проверка сборки:

```bash
npm run build
```

## Как поменять статус этапа

Все данные лежат в одном файле: `src/roadmap.ts`.

1. Найдите нужный этап по номеру `id`.
2. Поменяйте `status`:
   - `'done'`: выполнено
   - `'current'`: сейчас в работе (розовая карточка, пульс)
   - `'next'`: впереди
3. При необходимости поправьте даты: `date: '13.11'`. Если этап длится несколько дней, добавьте `dateEnd: '16.11'`. Пустая `date` значит «дата уточняется».
4. Сохраните файл и отправьте на GitHub (см. ниже). Сайт обновится сам.

Пример: этап 4 закончили, начали 5, 6 и 7.

```ts
{ id: 4, ..., status: 'done', ... },
{ id: 5, ..., status: 'current', ... },
{ id: 6, ..., status: 'current', ... },
{ id: 7, ..., status: 'current', ... },
```

Сами считаются: «Сейчас этап N / 13», полоса прогресса и процент, «День N из 7», календарь (цвет дней), группировка таймлайна по дням, счётчики в фильтре. «Сегодня» в календаре берётся по времени Алматы.

Поля этапа:

| Поле | Что это |
|---|---|
| `title`, `subtitle` | Название и уточнение под ним |
| `date`, `dateEnd` | Первый и последний день этапа, формат `'день.месяц'` |
| `what` | Что делаем |
| `why` | Зачем |
| `result` | Что получит клиника. Пустая строка `''` прячет пункт |

Остальное в том же файле:

- `received`: чек-лист «Получено от клиники». `received: false` покажет пункт как «ожидаем».
- `parallel`: блок «Параллельно» (обсуждение инструментов), у него свой `status`. Даты считаются из этапов `from` и `to`.
- `contact`: контакт в подвале (сейчас Telegram @thedmkr).
- `updated`: дата обновления в подвале. Если оставить `''`, подставится дата последней сборки по времени Алматы.

Не публикуйте на странице записи и тексты звонков, имена сотрудников, ответы опроса, логины и пароли.

## Как обновить сайт (GitHub Pages)

Сайт собирается сам при каждой отправке в ветку `main` (файл `.github/workflows/pages.yml`).

Через терминал в папке проекта:

```bash
git add -A
```

```bash
git commit -m "Статус: этап 4 выполнен"
```

```bash
git push
```

Через 1–2 минуты изменения появятся по ссылке. Ход сборки виден во вкладке Actions репозитория.

Без терминала: откройте `src/roadmap.ts` на github.com, нажмите карандаш, поправьте статус и нажмите Commit changes.

## Деплой на Vercel (по желанию)

1. vercel.com → Add New → Project → выберите репозиторий `roadmap-mushulov`.
2. Vercel сам определит Vite: Build Command `npm run build`, Output Directory `dist`. Нажмите Deploy.
3. Получите ссылку вида `https://roadmap-mushulov.vercel.app`. Дальше каждый `git push` обновляет и её.

## Приватность

- В `<head>` стоит `noindex, nofollow`.
- `vercel.json` добавляет заголовок `X-Robots-Tag: noindex` на Vercel.
- `public/robots.txt` запрещает индексацию.

Страницу видит любой, у кого есть ссылка, поэтому не кладите в неё ничего лишнего.
